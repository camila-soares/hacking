SecuForge — Bug Bounty Toolkit

Conjunto de ferramentas de recon e testes de segurança, para uso em engajamentos autorizados de bug bounty e pentest.

Recon automatizado

Subfinder, httpx, nuclei, gau, waybackurls, ffuf e dalfox integrados em um pipeline único.

Interface web

API e painel para acompanhar scans e resultados em tempo real.

Deploy self-hosted

Empacotado via Docker Compose, projetado para rodar em VPS próprio com autenticação por token.
